## 1. 計画

| MC（二次） | perc_2（情報不足）／perc_3（焦点ずれ）／perc_1（資料ずれ）の群間差。 |

## 2. 予備実験（MC検証）＝本実験の第1波（内部パイロット）

**第1波として本実験に含める条件。** 予備実験は本実験と同じ環境（本番 Worker）・同じプロトコル（`recipient-20260925-v8`）・同じ募集枠で行う。判定に使うのは MC（事実型3問・同意評定3項目・開示の想起）と手続き指標（滞在時間・資料参照・脱落・所要時間）だけで、主要結果（S・信頼・修復・負担・責任帰属）の条件差は判定前に集計しない。合格なら同じ募集枠で本実験の人数まで募集を続け、第1波の参加者をそのまま本実験に含める。不合格で刺激・依頼・文言・手続きを変えた場合は新しいプロトコル版にし、第1波は本実験から除外する（結果の探索的報告には使う）。判定の手続きと「主要結果を見ない」規則は募集前に事前登録に書く。

- 目的：v8の刺激と手続きで、参加者が3つのずれを検出するかを、募集前に固定した基準で判定する。本実験の人数はここから決めない。
- 人数：文書条件ごとに完了30人以上（差1.0・SD1.5で片側検出力0.83、事実型の一致率0.9対0.6で0.8以上）。**150人募集→完了120人前後**。開示は均等に振るが分析しない。
- 環境：本番単一環境（v7.2 と同じ Worker・D1）。旧データは protocol_version で区別する。
- 合否（事前登録に転記）：
  - 一次：3操作すべてで、操作対象問の意図一致率が操作条件で70%以上、かつ基準条件より高い（片側p<.05）。
  - 二次：perc_2／perc_3／perc_1 の対応する群間差が3つとも負で、うち2つ以上で片側p<.05（Holm 3比較）。
  - 手続き：報告案ページの滞在時間の中央値60秒以上、資料を開いた割合が旧パイロット（51%）より高い。
  - 除外は処置前指標のみ（同意直後の注意確認、重複、端末）。処置後のMC不合格者は落とさない。
- 不合格時の分岐：事実型だけ通る→事実型を主MCにして本実験へ。事実型も通らない→ゲート60秒、依頼A〜Dを読了画面に常時表示。資料ずれだけ通らない→資料を開いた人で層別、要点の常時表示に変更。特定テーマだけ→そのテーマだけ直し、盲検を通して再試験。

## 3. 本実験

- 主要結果 S の文書条件の主効果（操作 対 基準、3比較 Holm）：d=0.4 を両側α=.05・検出力.8 で拾うには1群 99〜131人 → **4群で約400〜520人**。開示との交互作用を主にする場合は d_int=0.4 でも1セル約200人（8セルで約1,600人）となり、現実的でない。交互作用は探索的に扱う。
- 詳細は `docs/POWER-v8.md`。

## 4. v7.2 からの変更点（アプリ）

1. 1人1案件（CASES_PER_PARTICIPANT=1）。Williams順と4案件の割付を廃止し、開示群内で文書条件を最少件数優先、条件×開示の中でテーマを最少件数優先。
2. 刺激24本と依頼文をv8入力（`stimuli-v8/`）から生成。条件名 `overreach` → `source_deviation`。
3. 知覚ブロックの先頭に事実型MC3問（テーマ別文言、はい／いいえ／覚えていない）。サーバで意図一致（`fmc_*_correct`）を付与。
4. 読了ゲート45秒（`READ_GATE_SECONDS`、テストでは短縮可）。予告文・監査型注意文。
5. 1案件向けの文言（説明、案件ラベル、振り返り、作成方法の想起）。所要時間・制限時間の表示。
6. 集計ツール `tools/pretest-summary-v8.mjs`（本番単一環境、第1波は募集開始時刻で抽出）。
